# 来点蓝色大肥鱼（AstrBot 插件）

`/来点蓝色大肥鱼 x` 从**图库仓库**随机发吊图，"x"表示来几张图，不加x就是一张。

## 用户上传

可以来到贴吧：大肥鱼表情包分享吧 发帖，我看到就会加入到图库里  

## 配置（WebUI → 插件 → 来点蓝色大肥鱼）

| 配置项 | 默认 | 说明 |  
| --- | --- | --- |  
| `gallery_repo` | `ZHYSNAKE/plugin_only` | 图库仓库 `owner/repo`，这个是Gitee的仓库 |
